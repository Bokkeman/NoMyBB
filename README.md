# NoMyBB

Browser extensions that clean headlines on MyBroadband, Newsday, and BusinessTech. They drop clickbait, name the vague places and people, and hide topics you choose to ignore.

- `nomybb` is the Chrome extension. Load that folder unpacked from `chrome://extensions`.
- `nomybbff` is the Firefox extension. Load that folder from `about:debugging` in Firefox 142 or newer.

Each browser keeps its own settings and cache. The Deepseek API key stays in extension storage and is sent only to api.deepseek.com.
