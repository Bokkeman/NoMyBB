# Chrome privacy-practices form

Answer from this extension's behavior. Do not certify that the extension collects no user data.

Privacy policy URL: the public HTTPS page you publish from PRIVACY_POLICY.md.

## Data the extension handles

Check these categories:

- Website content
- Authentication information

Leave the other categories unchecked. NoMyBB does not collect health data, financial data, location, web history, or the user's name, email, or address. An article may mention people; that text is website content, not a profile of the user.

## Website content

Collected and used for the single purpose: rewriting headlines, writing the summary, answering a follow-up, and suggesting selectors when the user chooses Automatic or clicks Inspect.

Transmitted to `api.deepseek.com`. Not sold. Not used for advertising. Not used to determine creditworthiness. Not used for any purpose unrelated to headline cleaning.

What is sent is described in PRIVACY_POLICY.md: the headline, article URL, a short excerpt, the user's ignore list, and, only when the user asks, the follow-up question and recent answers.

## Authentication information

The Deepseek API key is stored in extension storage on the device and sent only to `api.deepseek.com` so those requests can run. It is not sold and not sent anywhere else.

## Certifications

These statements are true for the current code:

- The data use is limited to the disclosed headline-cleaning purpose.
- Data is not sold.
- Data is not used for purposes unrelated to that purpose.
- Data is not used for creditworthiness or lending.
- The extension does not load remote code. The GitHub VERSION response is a version number and is not executed.

## Remote code

Answer no. All extension JavaScript is in the uploaded package.
